# 하늘길 질주

해 질 녘 도시 위로 에어카를 몰고 게이트를 통과하는 3D 비행 게임입니다. (three.js)

## 실행

`index.html`을 브라우저로 열면 바로 플레이할 수 있습니다. GitHub Pages로 배포해도 됩니다.

## 조작

| 키 | 동작 |
| --- | --- |
| W / S, ↑ / ↓ | 기수 올리기 · 내리기 |
| A / D, ← / → | 좌우 선회 |
| Shift, Space | 부스터 |
| P | 일시정지 |
| M | 소리 켜기 · 끄기 |

휴대폰에서는 화면의 조이스틱과 부스트 버튼으로 조작합니다.

# 백악기 사냥꾼 (`dino-hunt/`)

티라노사우루스가 되어 백악기 초원의 공룡을 사냥하는 3D 게임입니다. (three.js)

`dino-hunt/index.html`을 브라우저로 열면 바로 플레이할 수 있습니다.

## 조작 (리그오브레전드 방식)

| 입력 | 동작 |
| --- | --- |
| 마우스 오른쪽 클릭 | 땅: 이동 / 공룡: 추격하며 기본 공격 (왼쪽 클릭도 가능) |
| Q 박치기 돌진 | 일직선 돌진, 처음 부딪힌 공룡을 넘어뜨림. 3초마다 충전, 최대 3회 |
| W 물어뜯기 | 큰 피해와 출혈, 넘어진 대상 2배. 기본 공격 적중마다 재사용 1초 감소 |
| E 꼬리치기 | 몸을 돌려 주변을 모두 쳐서 밀어냄 |
| R 폭군의 처형 | Q·W·E 15회 사용 후 가능. 뛰어올라 찍어 누르고, 세 번 밟고, 물어 들어 땅에 내리꽂아 기절 |
| 마우스 휠 / S / P / M | 확대·축소 / 멈춤 / 일시정지 / 소리 |
